EurekaDock 1.5.0 — Windows 11 x64

【中文版】

请完整解压发行包，再双击最外层的 EurekaDock.exe 启动。它会调用 app 文件夹内的程序和随包提供的 Microsoft .NET 10 Windows Desktop Runtime（x64）；无需单独安装 .NET。也可运行 Start EurekaDock.cmd。

首次启动会为当前 Windows 用户创建干净配置，保存在 %LOCALAPPDATA%\EurekaDock。发行包不包含个人应用列表、快捷栏项目或保存的颜色。右键单击系统通知区域中的 EurekaDock 图标，可打开设置、重启或退出。

软件图标效果：
打开设置 → 软件图标，分别选择“点击反馈”和“常态显示”。两项默认均保留原有效果，可独立搭配，修改立即生效并自动保存。
• 弹跳（macOS 风格）：单击启动后向上弹跳，幅度逐次减弱；拖动和右键菜单不会触发。
• 镜面反射：在图标下方显示向屏幕外倾斜的倒影，向下逐渐模糊、渐隐，不添加背景托盘。
效果适用于 Dock 与快捷栏，继续使用现有图标大小、悬停放大和边缘渐隐设置。快捷栏启动项目后仍自动收起。选择“默认”即可关闭对应效果。反射预先生成并缓存；静止时停止动画计算。

条形音浪默认铺满整条区域。歌曲开始播放后显示封面与歌曲信息；暂停时保留，关闭播放器后平滑收回。其他声音不会收起暂停播放器的封面。详细教程见设置 → 关于与帮助。

软件完全离线运行，不采集麦克风、不上传音频，也没有遥测或自动更新。EurekaDock 采用 MIT 许可证（EurekaDock-LICENSE.txt）；Microsoft 运行时许可和第三方声明分别见 LICENSE.txt、ThirdPartyNotices.txt。

【English】

Extract the complete package, then double-click the outer EurekaDock.exe. It launches the app in the app folder using the bundled Microsoft .NET 10 Windows Desktop Runtime (x64); no separate .NET installation is required. You can also run Start EurekaDock.cmd.

On first launch, EurekaDock creates a clean configuration under %LOCALAPPDATA%\EurekaDock. Personal app lists, Quick Panel items, and saved colors are not included. Right-click its notification-area icon to open Settings, restart, or exit.

App icon effects:
Open Settings → App Icons to choose Click feedback and Resting appearance independently. Both defaults preserve the existing behavior. Changes apply immediately and save automatically.
• Bounce (macOS style): a launch click starts diminishing upward hops. Dragging and context menus do not trigger it.
• Mirror reflection: a reflection below the icon widens towards the viewer and progressively blurs and fades downwards, without a background tray.
Effects apply to the Dock and Quick Panel while retaining icon size, hover zoom, and edge fading. The Quick Panel still closes after launching an item. Choose Default to turn off either effect. Reflections are cached; animation processing stops when idle.

Bar Wave fills the full area by default. Artwork and track details appear when a song starts, remain while paused, and smoothly retract when the player closes. Other audio does not dismiss a paused player's artwork. For the full guide, open Settings → About & Help.

EurekaDock works entirely offline, with no microphone capture, audio uploads, telemetry, or automatic updates. EurekaDock uses the MIT License (EurekaDock-LICENSE.txt). Microsoft runtime license and third-party notices are in LICENSE.txt and ThirdPartyNotices.txt.
